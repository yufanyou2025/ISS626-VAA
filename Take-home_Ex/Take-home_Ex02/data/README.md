# Inputs for Take-home Exercise 2

## ACLED: required from eLearn

Download the Myanmar ACLED dataset supplied for this assignment from eLearn. Save its original CSV or Excel file under `data/raw/`, or provide its existing local path. The original file is not yet available in this workspace. Do not substitute a senior's processed dataset or fabricate an analytical sample.

After receipt, record its exact filename, SHA-256 hash, supplied coverage, schema, sheet name (if Excel) and extraction date if documented. The study window is 1 January 2021–30 September 2025. The raw input and event-level derivatives are excluded from Git and website resources.

## MIMU boundaries: downloaded and validated

- Source: [Myanmar Township Boundaries MIMU v9.4](https://geonode.themimu.info/layers/geonode%3Ammr_polbnda_adm3_250k_mimu_1).
- Layer: `geonode:mmr_polbnda_adm3_250k_mimu_1`.
- Metadata publication: 18 June 2023; accessed 8 October 2026.
- Format: WFS zipped shapefile, WGS84; 330 township polygons, all `PCode_V = 9.4`.
- Stable key: `TS_PCODE`. English labels: `TS` and `ST`.
- Run `source("Take-home_Ex/Take-home_Ex02/prepare-boundaries.R")` from the repository root. It downloads the boundary input if absent, checks the three pinned content hashes, and produces geometry and neighbour audits.
- ZIP timestamps are generated by the server. Hashes therefore pin the `.shp`, `.dbf` and `.prj` contents rather than relying on byte-identical download archives.

The boundary files are local, ignored inputs. MIMU's metadata and [terms](https://themimu.info/mimu-terms-conditions) restrict geospatial redistribution and online use. See `notes/brief-and-design.md` before publishing boundary-derived maps. Do not add the ZIP, shapefile, GeoJSON or geometry-bearing RDS to Git or the submission package without the necessary permission.
